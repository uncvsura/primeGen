Open repo and run "make" in terminal to compile everything. Ignore warnings.\
\
Run "./bitSieve" to start efficient prime generating algorithm.\

It will ask for a power of 10 as input and will generate all prime numbers up to this power of 10.\

For example: inputting 9 will generate all primes up to 10^9 = 1 billion.\

It will also ask whether you want to print the list of primes, 1 for yes, 0 for no. Be warned that printing takes a while.\

Rule of thumb: you need N bits of RAM to generate primes up to N. Generating primes up to 10 billion will require approximately 1.25 GB of RAM. Proceed with caution.
